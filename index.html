02 BIO / SAO LAB

Program BIO. Test SAO.

Upload a RISC-V binary, select SAO pins, set the clock, and exchange FIFO3 words.

PERSISTENT HARDWARE CONTROL

BIO programs persist across reboots and can drive SAO pins. Verify the binary and circuit first.

Replace & run

Stops the current program, clears its state, sends 60 chunks, and starts the replacement.

Command limits

Art and BIO use the stock firmware console. This app does not flash firmware, read FIDO credentials, or enable developer mode.

Factory, debug, and arbitrary console commands are blocked.
